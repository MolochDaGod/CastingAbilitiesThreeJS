# Casting VFX showcase (`/vfx`)

Page: `vfx.html` → `/vfx` (vercel.json rewrite). Code: `src/showcase/`.

## Sources (no invented assets)
| Section | Source | Plays with |
| --- | --- | --- |
| 3D casting effects (12) | `src/vfx/vfxCatalog.js` `VFX_CATALOG` | the game's own `VfxDirector` + `ParticleEngine` / `BurstSystem` / `DecalSystem` / `LightPool` (`src/showcase/vfxStage.js`) |
| Sprite sheets, projectiles, beams (157) | `public/api/v1/vfx-showcase-manifest.json` | animated billboard / ground decal on the same renderer; 2D canvas thumbnails |

The manifest is generated by `npm run vfx:manifest` (`scripts/vfx-sprite-manifest.mjs`) from
`https://info.grudge-studio.com/api/v1/effectSprites.json`. Every key is fetched from
`https://assets.grudge-studio.com` and kept only as `real` when the body has image magic
bytes; sha256, bytes and real width/height are recorded. Catalog grids that do not fit the real
image are re-fit or shown as one frame, with `layoutNote` saying so.

## Runtime rules
- Shared URLs are always `https://assets.grudge-studio.com/<key>`.
- The CDN hotlink allowlist admits `casting.grudge-studio.com`; on other hosts (previews,
  localhost) bytes come through the existing `/api/assets/*` proxy (`api/cdn-proxy.js`).
- The browser re-checks magic bytes; a miss shows the `icon missing` marker, never stand-in art.
- One `WebGLRenderer`; `setAnimationLoop` stops when the tab is hidden or the stage is off-screen;
  sprite texture / material / geometry are disposed on every switch; `dispose()` on pagehide.
